# Pale Store

Черновик магазина одежды. Название «Pale Store» временное, логотипа пока нет.

Стиль по референсам владельца: белый фон, светло-серые плитки под фото, шрифт Inter везде, серые кнопки-пилюли, полупрозрачные «стеклянные» плашки (шапка, ценники на главной, быстрое добавление, выбор размера, поиск, уведомление «Added to bag»).

## Как устроено

- Один файл `index.html`: CSS, разметка и JS. Сборки нет, можно открыть через любой статический сервер (`python3 -m http.server`).
- Страницы на хэше: `#home`, `#new`, `#clothing`, `#bags`, `#shoes`, `#accessories`, `#sale`, `#p-<id>` (товар), `#bag`, `#checkout`, `#order-<номер>`, `#wishlist`, `#account`, `#about`, `#contact`, `#faq`, `#privacy`, `#app`.
- Товары в массиве `P` в начале скрипта: бренд, название, категория, цена (`was` — старая цена для скидки), цвет, размеры, проданные размеры (`out`), фото, тексты. Одна модель в нескольких цветах — один товар со списком `variants` и выбором цвета на странице товара (`#p-<id>--<цвет>`). Цены и размеры пока заглушки. В разделах каталога можно выбрать бренд (список рядом с сортировкой).
- Корзина, избранное, вход и заказы хранятся в `localStorage` (`pale.v1`). Оплата не подключена: при оформлении есть выбор карты (Visa, Mastercard, UnionPay, American Express) и поля карты с проверкой, но деньги не списываются и номер карты не сохраняется; «Place order» просто сохраняет заказ.
- Промокод для проверки: `PALE10` (−10%).

## Фото

Все фото товаров в `assets/products/`: `<id>.jpg` — исходник, `<id>.webp` — версия для сайта. Версию для сайта делает `tools/photos.py`: фон приводится к серому плиток `#E7E7E7`, вещь ставится по центру кадра 3:4, поэтому фото сливаются с плитками и на главной стоят как одна сцена.

```
python3 tools/photos.py папка-с-jpg assets/products            # белый или ровный серый фон
python3 tools/photos.py папка-с-jpg assets/products --gradient # фон с перепадом яркости
python3 tools/photos.py папка-цветов assets/products --same-size # цвета одной модели: одинаковый размер и место
```
